## Issues to address in a future version

1. **Link destinations.** `shortcode()`, `live_shortcode()` and the BBCode/HTML snippets generated by `settings_page()` point to `home_url('/')`, even when the displayed domain differs. The “Displayed domain name” field does not control these links.
2. **Last valid readings after changing data source.** `sanitize()` clears CACHE and SCHEMA_CACHE but retains LAST_GOOD. If a newly selected endpoint returns no readings, the fallback can temporarily display readings from the previous source, marked as stale.
3. **Attribution.** The header lists `John Martin`. The English update does not change the author attribution.

These findings remain open; v0.4.5 changes language and documentation only.
