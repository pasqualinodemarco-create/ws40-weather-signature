WS40 Weather Signature 0.4.5

Dynamic weather banners for WordPress, web forums and email. The plugin installs into the permanent directory ws40-weather-signature.

Available designs

  • Light Breeze
  • Midnight Weather
  • Boletus Forest
  • Custom — editable colors, panels, transparency, weather captions and background image URL

Compact dimensions: 900 × 105 px. Card dimensions: 560 × 280 px. Weather measurements stay live in all designs.

Configuring Custom

Go to Weather Signature in the main WordPress admin menu. Select Custom, then adjust Branding and design and Custom banner appearance. Custom uses the colors and measurement-field visibility set in the admin. Its background can be a solid color, transparent, or an HTTPS image from your Media Library (up to 1.5 MB, maximum 6 megapixels). Save settings to refresh the gallery.

Embedding

[ws40_weather_signature style="custom"] or [ws40_weather_signature layout="card" style="custom"]. The gallery also provides the URL of each image. The plugin retains all existing shortcuts, JSON field mapping and the optional live HTML shortcode.

Changes in 0.4.5

All built-in interface and theme labels use English. Repository documentation and the installation guide are now entirely in English. Existing settings, data mappings and theme identifiers are preserved.

Changes in 0.4.4

Four designs, separate dynamic Custom renderer for PNG/SVG and removal of obsolete Classic PHP drawing code. Older style=classic and style=scenic links still fall back safely to active designs. PHP GD enables PNG; otherwise a self-contained SVG is returned.
